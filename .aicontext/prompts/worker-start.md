# Worker Start

Load what a worker needs for one step. No update check, no readiness report.

Read in full, per the Session Context Reuse rule in `process.md`:

1. `.aicontext/rules/standards.md` — safety rules and coding standards
2. `.aicontext/structure.md` — commands, testing, repository layout
3. `.aicontext/project.md` — project overview and constraints
4. `.aicontext/local.md` — project-local worker rules; overrides the files above

Confirm in one line: the project name and the test command. Then wait for the step handover.
